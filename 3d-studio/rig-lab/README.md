Minik Kasifler - Rigged Animal Walk Test

Uses the Chickensoft Mascot Model by Chickensoft / Thibaud Goiffon as a temporary demonstration, NOT the final Minik Kasifler character.
Source: https://github.com/chickensoft-games/Chicken
Model license: Creative Commons Attribution 4.0 (CC BY 4.0); credit is required.
Animations license: CC0.

Workflow downloads the source via git LFS, inspects the armature and walk/run/jump/idle actions, and renders a five-second 540x960 24fps test with the actual walk action.
This is a motion validation test, not a finished furry animation. The final rabbit and chick need original branded models.
